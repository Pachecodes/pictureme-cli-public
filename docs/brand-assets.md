# PictureME brand assets

The README uses the actual PictureME lockup, copied unchanged from the approved
brand masters. These are logo assets, not generated substitutes.

| Asset | Artwork | Intended background |
| --- | --- | --- |
| [Dark UI lockup](assets/pictureme-lockup-dark.svg) | White wordmark, lime mark | Dark |
| [Light UI lockup](assets/pictureme-lockup-light.svg) | Dark wordmark, lime mark | Light |

Both masters have a `0 0 2339.55 494.15` viewBox. Keep that intrinsic ratio:
set width only, never stretch, recolor, crop or redraw the artwork. The README's
HTML `picture` selects the correct variant for light or dark mode, with a light
fallback and descriptive alternative text.

The workflow illustration is an original explanatory **diagram, not a screenshot**.
It describes this client's interaction with the hosted service; it does not
promise a live deployment, a particular result or automatic approval controls.
It contains no scripts, external resources, embedded font files or personal data.
